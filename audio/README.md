# 参考音频目录

## 📁 目录说明

此目录用于存放孙悟空的参考音频文件，用于F5-TTS语音合成。

## 🎵 参考音频要求

### 文件规格
- **文件名**: `wukong_ref.wav`
- **格式**: WAV格式
- **采样率**: 16kHz 或 22kHz
- **时长**: 5-12秒
- **声道**: 单声道或双声道均可

### 内容要求
- **语音内容**: 清晰的孙悟空配音
- **语音质量**: 无背景音乐，无噪音
- **说话风格**: 符合孙悟空的性格特征
- **音量**: 适中，不要过大或过小

### 推荐来源
- 西游记动画片配音片段
- 游戏《黑神话：悟空》配音
- 经典影视作品中的孙悟空配音
- 专业配音演员录制的孙悟空语音

## 📝 参考文本

参考音频对应的文本内容应该在代码中设置，建议使用经典的孙悟空台词：

```python
ref_text = "俺老孙来也！妖怪哪里逃！"
```

或者：
```python
ref_text = "吃俺老孙一棒！"
```

## 🔧 使用方法

1. 准备符合要求的音频文件
2. 重命名为 `wukong_ref.wav`
3. 放置在此目录下
4. 在代码中设置对应的参考文本
5. 运行TTS系统进行语音合成

## ⚠️ 注意事项

- 参考音频的质量直接影响最终的语音合成效果
- 建议使用多个不同的参考音频进行测试，选择效果最好的
- 如果合成效果不理想，可以尝试调整参考文本或更换参考音频
- 确保音频文件没有版权问题

## 🎯 效果优化建议

1. **音频预处理**:
   - 使用音频编辑软件去除背景噪音
   - 调整音量到合适水平
   - 确保语音清晰度

2. **文本匹配**:
   - 参考文本应与音频内容完全匹配
   - 包括语调、停顿等细节

3. **多样化测试**:
   - 准备不同情绪的参考音频
   - 测试不同长度的参考片段
   - 比较不同来源音频的效果
